
# Student Result & Grade Calculator

A simple and responsive web application that calculates student results based on marks entered for five subjects.

## Features

- Enter student name and subject marks.
- Calculate total marks, percentage and average.
- Automatically assign grades based on percentage.
- Check pass or fail status.
- Display subject-wise marks and results.
- Validate student details and marks.
- Light and dark theme options.
- Reset the form.
- Print the calculated result.
- Responsive design for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Grading System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89% | A |
| 70–79% | B |
| 60–69% | C |
| 50–59% | D |
| 35–49% | E |
| Below 35% | Fail |

A student must score at least 35 marks in every subject to pass.

## How to Use

1. Download or clone the repository.
2. Open the `index.html` file in a web browser.
3. Enter the student's name.
4. Enter marks for all five subjects.
5. Confirm the entered details.
6. Click Calculate Result.
7. View the calculated result.
